GITHUB PAGES UPLOAD
1. Create or open the GitHub repository you want to use.
2. Upload the entire contents of this folder while preserving the assets/ and data/ folders.
3. In GitHub: Settings > Pages.
4. Set Source to "Deploy from a branch" and choose the main branch / root folder.
5. Save and wait for GitHub Pages to publish the site.

IMPORTANT
Do not upload only index.html. The app depends on styles.css, app.js, the assets folder, and the data folder.

DATA SOURCE
College requirements were parsed from the uploaded 2026-27 Common App First-Year Deadlines, Fees and Requirements Grid, updated 08-10-2026. The app intentionally displays blank source cells as "Not indicated" and preserves "See Website" where Common App directs users to institution-specific information.

GUIDE / GLOSSARY SOURCE
Guide content and glossary entries were developed from the uploaded Common App student resources, including the first-year quickstart, application dictionary, FERPA guide, activities guide, testing guide, recommendation guide, fee-waiver guide, requirements worksheet, and gather-materials checklist.

PRIVACY
My Applications and checklist progress use local browser storage only. No student data is sent to a server.
